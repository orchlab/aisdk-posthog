# Security Policy

## Supported versions

Only the latest minor release line receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting:
<https://github.com/orchlab/aisdk-posthog/security/advisories/new>

Include a description, reproduction steps and the affected version. You can expect an initial
response within a few days.

This package forwards LLM telemetry (prompts, outputs, token usage) to PostHog. Reports about
unintended data exposure in what is captured are in scope.
